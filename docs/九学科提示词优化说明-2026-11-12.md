# 九学科提示词优化说明

日期：2026-11-12。本次已修改项目源码，覆盖语文、数学、英语、物理、化学、生物、政治、历史、地理。规则同时进入评分标准生成、生成标准的保存内容及实际阅卷请求。

项目目前依据教师提供的题目和参考答案生成评分标准草稿。它不会在缺少依据时自行补出参考答案；识别原文与核验其正确性分开，发现参考答案疑似错误须提示教师，不能静默改写。

## 公共给分边界

- 按实际设问判断任务。空格中填写的解释、实验设计和论证，不能仅因外观是填空就一律采用答案全对或全错的规则。教师明确选择“按答案逐项给分”时，遵守该方式。
- 理科宽松模式：正确答案配相关有效过程必须给分。足以支持结论时给满分，否则给已经体现的部分分。完全只写答案的过程题不给过程分，明确设置的答案分仍可给；客观题不增加过程要求。
- 正常、严格模式同样接受有效等价解法。严格要求须写进本题具体条款，不凭印象增加固定扣分、封顶或一票否决。
- 看清学生实际保留的内容，结合题内编号、箭头和明确订正确定归属。清楚划掉的旧答案不计入；未删除的互相矛盾答案不能只挑正确项。无法确认归属且影响得分时报告识别疑点。
- 重复同义要点不重复计分；多写的无关内容不自动抵消独立正确要点。限定数量、多答、矛盾内容须在生成标准时明确本题处理方式。
- 局部错误只影响相应要点及真正依赖它的内容；不因前问出错否定独立成立的后问，也不凭正确终值补出未写过程。
- 教师补充、自定义要求和已保存的明确分值条款优先。默认模板不能临时改写旧标准的分值或给分边界；发生实质冲突时提示核对。
- 原文、图表、听力或关键条件缺失且影响判断时，生成阶段报告 `warnings` 并停止生成受影响标准；阅卷阶段报告评分规则疑点。
- 不按字迹美观、篇幅长短、疑似 AI 文风或与范文措辞相似程度直接评分。题目明确考查的字形、字数及格式仍按具体标准处理。

## 逐科核对及补充场景

| 学科 | 新增检查与真实作答示例 | 判分边界 |
| --- | --- | --- |
| 语文 | 阅读概括合并表述、术语错但分析有效、文言意译、省略句补意、默写异体与版本、作文不同立意 | 不逐字匹配范文；错字与正确异体需区分；词义与句意按独立要点评价，作文同一问题不重复扣分。 |
| 数学 | 分数与小数、集合与区间、参数命名、除以可能为零的式子、平方增根、证明与举例、整数应用范围、概率条件 | 先在定义域内核验等价；端点、漏解、增根和无效推理是实质问题；图上看起来成立不代替证明。 |
| 英语 | 英美拼写、缩写、主被动改写、简答摘录、否定与情态强度、应用文身份语域、续写不同情节 | 固定词形题遵守限定形式；开放表达以准确语义和任务完成为准；局部语言错不抹去整段内容分。 |
| 物理 | 刹车代入负加速度、假设电流方向、整体变号、参考系与零点、变化量与减少量、停车后的阶段、图像斜率面积、仪器读数 | `v=v0+at` 代入负的 a 合法；依据可见代入和上下文判断，不凭公式加号判错；错误模型不能由碰巧正确的数值抵消。 |
| 化学 | 名称与结构表示、分子式相同而结构不同、离子拆分、比例系数、反应条件、限量与产率、气体状态、现象与解释分离 | 表示法须回答所问对象；原子与电荷守恒、物质和条件分别核验；不把配平正确当成整式正确。 |
| 生物 | 结构层次、激素酶受体对象、不同有效对照、探究预测多种结果、遗传字母变化、条件概率、相关与因果 | 有效替代实验可认可，不强迫所有实验用空白对照；不把预测写成必然结论，不猜补未写的机制链。 |
| 政治 | 原因与意义、材料与原理联系、不同有效评析、政府企业公民主体、历史政策语境 | 不以关键词堆砌代替分析；措施须符合主体权限；按题目时间和材料核验，不编造法条政策。 |
| 历史 | 事件别称、译名历法、时序错置、作者观点与史实、史料可靠性、原因目的影响、比较与开放论述 | 一手史料不等于全部真实；不同观点需史实支持；局部日期错只影响相应事实及其依赖论证。 |
| 地理 | 半球季节尺度、风向与流向、总量与增长率、图例单位、等值线与时区、区域比较、替代治理措施 | 不以曲线上升推断所有指标上升；措施需适合本区条件；按设问决定是否要求正反两面。 |

这些条款是本项目的默认设计，不代表任何考试的统一官方评分政策。生成时只提取本题适用内容，不能要求学生每题都覆盖整套学科检查清单。

## 规则疑点如何落地

### 宽松误扣分案例与实际口径

刹车案例中，学生写出15m/s、−6m/s²、2秒末3m/s、2.5秒已停车，并用3²/(2×6)=0.75m计算第三秒位移，过程已体现停止前的有效区间。宽松口径不要求重复说明“2至2.5秒”或“运动0.5秒”，按3、3、4分分配应为10分。

后续明确：正常口径同样应得10分。九科通用的充分证据满分判断现同时用于正常、宽松；严格也不能临时添加区间说明扣分，只有本题标准事先明确要求与扣分时才适用。三档区别在对实际缺失过程和已规定书写细节的要求，不靠人为制造分差体现。对比见[三档评分口径与示例](三档评分口径与示例.md)。

实际提示不再固定称模型为“严格阅卷老师”。方案新增“实际阅卷口径”，显式选择并保存后，优先于旧模板模式标记和仅适用于其他模式的模板条款；本题特别指定要求与分值保留。未显式选择时继续解析已保存标准和生成设置。主评、复评、仲裁共用实际口径，结果记录expectedGradingMode，模型协议增加gradingMode。

生成与评分均先核对可见的有效证据是否满足本口径的整体满分条件，之后才处理未满足情形的部分分。公式、代入、中间结果与明确归属的前问结论可共同构成证据；不从正确终值猜补未写过程。生成规则须说明观察证据、必要前提、分值、同时满足或任一满足、替代路径和封顶，避免逐条累加造成同一能力重复扣分。

模型报告错误口径，或非严格模式明确使用严格标准扣分时，程序按原答卷有限重评一次，保留首次结果及核验状态。重评仍冲突、失败或预算不足，沿现有路径转人工确认，不自动改成满分。该检查针对明确口径冲突，不能保证识别所有隐性误扣；本例验证使用模拟模型，没有重放用户真实答卷或改写平台分数。

### 生成阶段的阻断问题

关键资料缺失、教师要求冲突或无法核验的参考答案实质问题，使用blockingIssues数组报告位置与原因。只要非空，服务端清空可执行标准，即使模型同时返回了items也不采用。普通分配建议保留在warnings，不阻断可用草稿。旧模型未返回blockingIssues时继续兼容；程序不能代替模型发现未报告的实质问题。

实际阅卷 JSON 增加 `gradingIssues`，无疑点为 `[]`，有疑点时列 `{location, reason}`。它用于缺少决定性条款、条款冲突、必要资料缺失及无法核验的参考答案疑点。普通答错、有效简写、合理替代解法不属于规则疑点。字迹及归属不清继续使用 `recognition`。

程序汇总最终结果以及双评、仲裁中的规则疑点，写入已有人工核对提示。即使两个模型总分一致，也不能抹掉其中一路报告的未解决规则疑点。无人值守因此转入人工确认，停止自动填分和提交；疑点也在历史详情中显示。旧模型响应未返回该字段时继续兼容。

这一机制依赖模型如实报告问题，并不能保证发现所有歧义。生成和评分测试主要验证规则传递、结果处理和操作边界，不能证明真实判分准确率。

## 实现位置与导出

### 应用流程中的统一接入

编辑器重新打开标准和服务端实际阅卷共用 `rubricGradingSettings`：标准中明确的学科、评分口径与给分方式优先于旧生成设置。只在没有相应标记时沿用原设置；兼容字符串及带图片字段，保留教师备注和自定义文字。该解析不会改写旧标准或分值。

实际评分使用 `gradingPolicyForRubric`。若标准已经完整包含当前共享规则，则不重复追加；旧标准缺少规则时补入共享核验边界，并强调保存条款优先。执行时单独明确给分方式，防止“按答案逐项给分”被过程分模板干扰。

生成器界面展示九科各自的核验重点，选择自定义时显示采用教师要求。Windows 打包检查将共享学科模块与规则疑点处理模块列为必需文件；自检在实际浏览器中打开生成器，逐科检查九个模板能够加载。此项自检不调用外部模型。

- `ui/subject-review-rules.js`：九科专项规则与公共真实场景边界。
- `ui/rubric-prompts.js`：共享到生成和阅卷；自定义模式跳过本次新增学科默认条款，保留公共边界及教师优先级。
- `src/domain.mjs`、`src/models.mjs`、`src/grading-issues.mjs`：评分协议、双评结果疑点汇总与人工确认。
- `src/server.mjs`：浏览器加载新共享模块；`ui/result-details.js`：历史详情展示核对提示。
- `test/subject-review.test.mjs`：九科三种口径、生成到保存再到评分的传递、长度、自定义优先级和阻止无人值守提交。

运行 `node scripts/export-prompts.mjs` 生成 27 份完整请求快照，以及每科一份 Markdown（每份含宽松、正常、严格）。运行 `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/package-prompts.ps1` 同步导出并压缩为九份 Markdown 的 ZIP；该命令的执行策略参数仅用于本次进程。

导出使用自动区分题型、10 分、步长 1 分、无图片及占位题目答案；不包含真实答卷、接口密钥或教师数据。发给其他 AI 时，将其中提示词视为待审阅文本，替换占位输入后才能实际使用。其他给分方式和自定义组合仍由运行时生成。

旧方案不会被批量重写。若需完整采用新模板，请重新生成、检查并保存评分标准，再用已经人工判分的真实答卷试评。本次修改尚未发布为新的便携包。
