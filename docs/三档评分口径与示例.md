# 三档评分口径与示例

适用于本项目默认规则。题目特别指定的方法、证明、精度等要求，以及教师明确的分值分配，仍须遵守。三档按证据与任务判分，不凭“看起来会做”猜补缺失内容。

## 共同底线

正确有效的不同解法、合并步骤都可以得分。不逐字匹配参考答案，不按行数评价过程。同一问题不重复扣分，错误结论不因选择宽松就当成正确。完全只写答案的过程题，不补过程分，已有明确答案分仍按标准给；选择、数值填空等客观项不额外要求过程。

过程不够工整与缺少关键依据是两件事。正常、宽松口径中，必要关系已在公式、代入、图示或归属明确的前问结果中体现，就不能因没另写一句解释扣分；满足本题满分要求应得满分。严格口径只对本题事先明确的书写细节追加核对，不临时发明扣分。

## 三档差异

| 口径 | 评价重点 | 省略过程如何处理 |
| --- | --- | --- |
| 宽松 | 优先认可已体现的方法、正确结论和有效内容，对常规计算与表达省略更宽容 | 有相关有效过程必须给相应分；足以支持结论给满分，不足时给有效内容的部分分，不能凭终值补齐证明等关键依据。 |
| 正常 | 关键关系、必要运算或论证有可核验依据 | 不要求逐行展开；已由合并式、代入或上下文体现的关系算已完成。实际缺少决定性关系时按具体条款扣对应分。 |
| 严格 | 在正常要求上核对已明确的单位、基本关系、符号说明等书写要求 | 只对事先规定的必写内容按对应条款扣分；替代解法、正确合并步骤仍可认可。 |

宽松与正常经常给相同分数。不能为了使三个模式看起来不同，人为制造扣分。同样，严格不意味着每份正确简洁的作答都必须失分。

## 示例一：第三秒刹车位移

学生写出初速度15m/s、加速度−6m/s²、2秒末速度3m/s、2.5秒停车，随后计算第三秒位移3²/(2×6)=0.75m，但没另写“第三秒只运动0.5秒”。前两问分别3分，第三问4分。

- 宽松：10分，已有有效过程充分支持正确结论。
- 正常：10分，停车时间与2秒末速度已经明确体现剩余制动区间。
- 严格：若标准没有单列区间说明的必写要求，也应10分。只有标准事先明确要求另写区间说明，并规定该遗漏扣1分，才按这条细节扣为9分；不能临时套“严格核对”扣1分。

## 示例二：结果漏写单位

设题目和上下文已明确位移单位为米，学生公式、代入与数值都正确，末行写“x=12”，漏写m，且题目没有特别要求展示单位。

- 宽松、正常：含义明确时不因这一表达省略扣分，可建议补写单位。
- 严格：若本题标准明确规定最终位移必须带单位及对应扣分，则按该条款处理；未规定时不能临时设扣分。

若学生写成12m/s，这是明确的量纲错误，三档均按实质错误处理；题目本身考查单位时也不适用上述省略容错。

## 示例三：简洁解法与真正缺少依据

解方程x²−5x+6=0，学生只写“(x−2)(x−3)=0，所以x=2或3”。这是完整有效的简洁解法，三档均可满分，不能要求重复展开因式分解过程。

证明题只写“由图可知成立”，没有可核验的论证，即使结论正确，也不能因为学生似乎理解图形就给证明满分。宽松认可实际有效的部分，但不补造论证；正常按缺少的关键依据处理；严格再核对本题明确的书写要求。具体得分须依本题分配，不能统一规定扣1分或固定比例。

## 项目中的使用

在阅卷方案中选择“实际阅卷口径”并保存，主评、复评、仲裁均使用这一口径。九学科生成提示与实际阅卷共用充分证据规则；物理刹车案例明确覆盖正常、宽松两档。模型报告错误口径或明确套用严格标准扣分时，有限重评一次；冲突未解决转人工确认，不按关键词自动加分。

这些示例用于说明项目规则，不是任一考试的统一评分细则。自动测试验证规则传递和异常处理，真实模型仍需用人工已判分答卷试评。
